# SysServicios — Caso 27: Padrón unificado de servicios públicos

Sistema de escritorio (JavaFX + Maven) para registrar solicitudes de servicios públicos.
Cada solicitud tiene: solicitante, domicilio, tipo de servicio (agua, alumbrado, recolección de basura, bacheo)
y estado del trámite (recibido, en atención, resuelto). Los datos se guardan en un ArrayList.

Ejecutar: mvn clean javafx:run
